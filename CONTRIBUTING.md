# Contributing to Multimodal Visual Search

Thank you for your interest in contributing! This project is part of a computer vision research portfolio.

## Getting Started

```bash
git clone https://github.com/sherifabdelrady/visionlang
cd visionlang
pip install -r requirements.txt
python search.py --help
```

## Dataset

This project uses **COCO / custom**. See the README for download instructions.

## How to Contribute

1. **Bug reports** — Open an issue describing the bug, your environment, and reproduction steps
2. **Performance improvements** — Open an issue first to discuss the approach
3. **New features** — Fork the repo, make your changes, open a PR with a clear description

## Pull Request Guidelines

- Keep PRs focused — one feature or fix per PR
- Include a brief description of what changed and why
- Make sure existing code runs without errors after your change
- Follow PEP 8 style for Python code

## Reporting Issues

Include:
- Python version and OS
- GPU/CPU environment
- Full error traceback
- Minimal reproduction script
